Privacy Policy

Effective date: 2026-11-01

This policy covers the personal OAuth client for rclone described on the home page. The client is used by a single person, its owner, to access the owner's own Google account.

Data accessed

With the owner's permission, the client accesses files and file metadata in the owner's Google Drive through the Google Drive API (scopes: drive, docs, drive.metadata.readonly).

How the data is used

The data is used only to upload, download, list, and sync the owner's files as the owner instructs, for the owner's own backup and file management.

Storage

Files move directly between Google Drive and the owner's own computers. The OAuth token is stored only in the rclone configuration on the owner's computers. No server is operated for this client, and no one other than the owner receives any of this data.

Sharing

Google user data is not shared with, sold to, or transferred to any third party. It is not used for advertising, and it is not used to develop, improve, or train generalized AI or machine-learning models.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact

Questions about this policy can be raised through this site's GitHub repository.
